Fitness Claude

An AI coach that programs every workout I do, and shows its reasoning

A spare-time build by Matt Smith · running daily since May 2026

Six scheduled Claude agents read my training history in Notion, decide tomorrow's session, and send it to my phone every evening.

The outcomeIt has run every day for months, and I've followed its programming with my own body the whole time. Improved a knee injury. Hit PRs in every training block since it started. That's my bar for trusting an agent.

The guardrails are scar tissue. A failed API call once retried itself in a loop and burned $3.64 and 820K tokens on the same request. Now agents fail cheap and loud: spend limits, retry caps, errors surfaced where I'll see them. A 2 AM platform re-run once sent a duplicate briefing and archived a live workout sheet. Delivery windows are now enforced in worker code, not in prompts.

Back — travel gym B1 · Seated Cable Row — 3×8-10, reverse pyramid B2 · Lat Pulldown — 3×10-12 B3 · Single-Arm DB Row — 3×10/side B4 · Straight-Arm Pulldown — 2×12-15 B5 · DB Curl — 3×10-12 B6 · Back Extension — 2×12 Worksheet created in Notion — edit it at the gym, the system reads it back tonight.
From the run log: why this plan
  1. Computed the block clock first. Day 4 of 35, inside the open PR window. Every later decision keys off this.
  2. Caught a plan override. I trained push instead of the prepared workout and logged it in chat. It counted the real session as the record instead of marking the day skipped.
  3. Found a travel note. Away gym for three days, so the plan uses cables and dumbbells it can count on.
  4. Picked pull. Longest gap at 15 days, and it doesn't load the flagged knee. Dropped rear-delt work because yesterday's session already hit it.
  5. Held the PR. The window is open, but yesterday's pressing was below proven weight and a shoulder flag was inside its cooldown. It says so in the briefing instead of deciding silently.

03How I know it's good

Grounding and hard rulesThe agent works from an Athlete File: who I am, current build, PRs, injury state. A second agent rescans the logs weekly and keeps that file current. Before it existed, the coach hallucinated PR weights and workouts I'd never done. On top of the file sit rules the output must pass: heaviest compound first, a ceiling on blocks per session, PR attempts only in the first two weeks of a block. That last rule gets checked again by plain code. [MATT — approve/edit]

Judgment as the evalBad outputs are obvious to someone who's trained for years: weights that contradict history, machines that don't exist, an exercise order no lifter would run. I've been the eval harness every day since May. [MATT — approve/edit]

Scaling it honestlyMy checks live in my judgment, and that doesn't scale. To productize this I'd turn them into an automated eval: a golden set of user profiles with known-good programming, every model or prompt change scored against it, failures tracked by type. New personas, like yoga or someone with no training history, would need new guardrails before I'd trust it with them. [MATT — approve/edit]
