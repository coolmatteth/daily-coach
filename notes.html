Building an AI coach that ran itself for four months

Matt Smith · August 2026

In May I had some free time and started tinkering: could Claude be my fitness instructor? Not a chatbot I ask for workouts, but a system that programs my training on its own, every day, from my real history. Four months later it still runs daily. I've followed its programming with my own body the whole time, improved a knee injury, and hit PRs in every training block since it started. The demo is here. These are the notes. It broke a lot first

The early responses were robotic and poorly designed. One night a Notion API call errored and the agent retried the same request in a loop until it had burned $3.64 and 820K tokens on nothing. That one taught me the most important lesson in this project: agents fail expensively and silently unless you make them fail cheap and loud. Now there are spend guards, retry caps, and every error gets written where I'll actually see it, so I can diagnose instead of discover. [MATT — approve/edit]

It also hallucinated. PR weights I'd never lifted, machines that don't exist, workouts assigned to the wrong day of the week. Each of those became a grounding fix: an Athlete File in Notion that says who I am, what I lift, and what's injured, kept current by a second agent that rescans my logs weekly; and a daily calendar sync so the planner always knows what day it is and what I actually trained. Boring infrastructure, and it killed whole categories of error. [MATT — approve/edit]

Rules beat vibes

The rules I'd use as my own trainer are encoded as checks the output must pass, not suggestions in a prompt: heaviest compound first while you're fresh, a ceiling on blocks per session so it can't overprogram, PR attempts only in the first two weeks of a fresh training block. The PR rule matters enough that plain code checks it a second time and strips the flag if the model gets it wrong. The model proposes; deterministic code disposes. [MATT — approve/edit]

How I know it's good

Honestly? Because I've trained for years and bad outputs are obvious to me: weights that contradict history, an exercise order no lifter would run. I've been the eval harness every single day since May. That works for a system with one user who's an expert in the domain. It does not scale, and knowing that is the point: to productize this I'd formalize my checks into an automated eval, a golden set of user profiles with known-good programming, every model or prompt change scored against it, failures tracked by type. And whole new personas, yoga, barre, someone with no training history at all, would need their own guardrails before I'd trust the system with them. [MATT — approve/edit]
